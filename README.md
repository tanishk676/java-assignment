### Compilation and Execution Instructions

To compile and run any task independently:
```bash
# Navigate to the specific task folder, for example:
cd Assignment-01-Reading-Array-Values/Task-1

# Compile
javac Main.java

# Run
java Main
```

To compile and test all 46 tasks automatically, run:
```powershell
./run_all.ps1
```
or on Command Prompt:
```cmd
run_all.bat
```
